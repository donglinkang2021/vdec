Drawing 规则与当前画面

Drawing v3 将画板编辑能力接入正式环境。共 704 道冻结题：dev 176、test 352、OOD 176，22 个家族、66 个模板。其中保留 512 道原空间关系题，新增 192 道路径、配色、拉伸、顶点、图层与组合编辑题。原题 ID 保持稳定，新版本成绩按 v3 与引擎指纹报告。

先读目标，再操作和提交

Section titled “先读目标，再操作和提交”

已有对象标明 ID 与是否锁定。按照题目新增或编辑对象，再抬笔并提交。用户沙盒、Python 评测、规则参考解与本文图片使用同一内核。首页自定义作品仍是程序演示，不生成正式成绩。

动作与两条轨道

Section titled “动作与两条轨道”

geometry 支持 line、rectangle、circle、ellipse、polygon、pen、eraser；freehand 使用 pen、eraser。两轨都能编辑已有对象。13 类动作的顺序为：

动作效果
tool / color / fill_color设置工具、描边色、独立填充色
style / width设置空心或实心、笔宽或橡皮直径
move / down / up移动笔尖、落笔、抬笔提交一个对象
select / edit按可见 ID 选择，再修改一个对象或一组对象
undo / redo撤销或重做最近场景修改，保留 100 次历史
finish提交当前作品

坐标为整数 0–80，RGB 通道 0–255，笔宽 1–32 像素。geometry 默认 192 步，freehand 默认 768 步；没有固定对象数上限，正式题目仍受动作预算约束。参数选择本身不执行动作；非法参数消耗一步并保持场景不变。

编辑与多选

Section titled “编辑与多选”

select 可替换、添加、移除或切换选择。组内包含锁定对象时，编辑整体拒绝。组移动、旋转和等比缩放以组合可见墨迹包围盒中心为基准。

edit operation参数与规则
movex、y：移动可见中心
rotateangle：顺时针 −180～180 度
scalepercent：整体等比缩放 25～200%
resizewidth、height：单对象可见墨迹宽高，1～80 单位；圆的宽高必须相等
vertexindex、x、y：修改线段、多边形或笔迹的控制点，序号从 0 开始
color / fill_color / style / width修改所选对象的描边、填充、样式或笔宽
layerposition：front、back、forward、backward，保持所选对象之间的顺序
delete删除所选可编辑对象

变换不能把墨迹移出画布。擦除痕迹在编辑和变换后保留；重做不会重新执行模型请求。网页的缩放和平移只改变观察视图，不是模型动作。

怎样评分

Section titled “怎样评分”

原空间关系题仍从剩余无损墨迹拟合形状，再检查颜色、填充与关系。新路径题与画面中可见的参考轮廓比较双向距离，不根据对象名称或工具标签判定正确；独立填充色和规定笔宽也要符合。图层题检查对象的实际叠放顺序，要求保留的对象不能被删除后重画替代。

遗漏对象、额外墨迹、未完成笔画、错误层叠或未提交都不能通过完整成功率。位置/轮廓容差仍为 8 像素；常规测试与 OOD、geometry 与 freehand 分别报告。

模型怎样发出动作

Section titled “模型怎样发出动作”

coordinate 每次生成一个 JSON；readout 先选择动作，再选择参数。move 和顶点坐标通过四轮九宫格定位，RGB 与其它整数通过逐轮缩小范围选定。完整参数确定后才执行一次环境动作。模型不会收到目标坐标表、参考动作或中途评分。

每行是一条独立动作。独立填充、顶点和图层步骤都属于 v3 正式协议，不再借用首页私有步骤。
