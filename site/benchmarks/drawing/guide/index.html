增加的是结构，不只是换颜色

Section titled “增加的是结构，不只是换颜色”

每个家族有三个模板：前两个分别生成 4 个开发实例和 8 个常规测试实例，第三个模板只出现在 OOD 测试中。因此开发集为 128 题，常规测试 256 题，未见模板测试 128 题。两种测试分别报告；默认冒烟仅选开发集每家族一题，共 16 题。

geometry 支持直线、矩形、圆、椭圆、多边形和橡皮，预算 192 次；freehand 支持真实画笔和橡皮，预算 768 次。两轨使用同一题目。每题初始对象 2–10 个，最终评分目标最多 8 个；所有题目与参考轨迹在 Python 环境中执行。

11 个操作，三种选择方式

Section titled “11 个操作，三种选择方式”

原七个操作的字母顺序不变：A tool、B color、C move、D down、E up、F undo、G finish。新增 H style、I width、J select、K edit。选择动作与参数的过程中，真实笔尖、颜色和擦除掩码都不变；参数齐全后才执行一次环境操作。

choice：同一请求列出 A–K，输入尾部预填 \boxed{，读取候选字母的下一 token 分数，取最高项映射为操作。选到 C 之后，仍需四轮九宫格定位，每轮一道九选一题。

yes_no：同一画面分别询问 11 个操作是否最佳，每题同时读取 yes/no 两个候选的分数。比较各题的 yes 相对概率，取最高项；不是遇见第一个 yes 就执行。一次批处理可以装多题，但仍按题数计请求。

coordinate：一次生成规范 JSON，同时表达操作和参数，例如 {"action":"color","rgb":[128,64,192]}。严格解析整数、字段和范围；非法动作消耗预算，不自动截断或纠正。

完整 RGB：12 次参数选择，一次换色

Section titled “完整 RGB：12 次参数选择，一次换色”

先选“16 个预设 + 自定义 RGB”之一。自定义时依次选择 R、G、B：每个通道四轮四分，256 → 64 → 16 → 4 → 1。三个通道都完成后才提交一次 color。明确 RGB 指令精确匹配；看图匹配颜色时每通道允许 ±8，模型看不到参照对象的隐藏 RGB。

评分检查最后剩下的墨迹

Section titled “评分检查最后剩下的墨迹”

局部橡皮沿实际移动线段擦除。选中对象时只擦这个可编辑对象，未选中时擦所有可编辑对象；锁定对象不受影响。活动绘制或擦除可以撤销，完成后的撤销恢复最近一次场景变更之前的状态。工具或颜色选择不占场景撤销历史。

评分先从实际墨迹拟合几何形状，再匹配颜色、填充和空间关系；不拿隐藏参考坐标作为标准答案。空心不能冒充实心，残缺轮廓、额外笔迹与未完成笔画都会影响终局判分。合法遮挡按对象自身墨迹评估，擦除则改变该对象的有效墨迹。
