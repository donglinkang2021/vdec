查看随机与固定策略的计算方法

这些参照全部在当前 dev 的冻结数据和主评分规则上重新计算；旧 benchmark 说明页的参考表使用 all 划分，不能直接当作 dev 实测复制。规则参照不运行模型，也没有 GPU 延迟或生成重复。“均匀乱选”直接作用于最终语义答案，不是给 yes/no 的每个候选随意抛硬币再取最高分。

  • Perception 独立乱选期望：(1/4 + 1/3 + 1/3 + 1/5) / 4 = 27.92%，按四类等权。
  • Readout 独立乱选期望：3 × (1/3)⁶ = 1/243 ≈ 0.41%。必须六次都选同一个语义动作才记 1；先随机选一次再复用六次，则是 100%，属于另一种策略。
  • Safety 独立二元乱猜的完整集合正确率为 (1/2)³ = 12.5%。全部判安全／危险各只在一个安全动作数层得满分，四层等权后均为 25%。
  • Decision 均匀乱选期望为 (1/3 + 2/3) / 2 = 50%；固定左／直／右在当前平衡 dev 集也都是 50%。

— 表示该策略在该任务下没有定义，不是零分。固定字母 A 指选择显示第一项；yes/no 没有字母输出，此行仅作为位置策略参照。
