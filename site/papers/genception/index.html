GenCeption：从视频生成到视觉感知

正文与示例可直接阅读；加载后可查看保存的请求与逐步操作。

GenCeption 用监督训练，将视频生成模型改为感知模型。它可预测深度、表面方向、分割和坐标。

先看各任务结果，再查看输入输出表示与训练方法。单任务版本和联合训练版本分别报告。

论文 · Letian Wang 等，2026版本 · arXiv:2607.09024v1论文说明 · 论文说明

研究问题：生成预训练能否帮助感知

Section titled “研究问题：生成预训练能否帮助感知”

论文研究：视频生成预训练的表示，能否用于视觉感知？ 它不直接测试物理推理或动作规划。

GenCeption 从 WAN 2.1 开始，保留视频 VAE、文本编码器和扩散 Transformer（DiT）。监督后训练将输入改为视频与任务文字，输出改为目标模态。

这里的“预训练”指此前的视频生成学习；“后训练”指用带有感知标签的数据继续训练。浏览器中的例子只帮助理解，不运行这些模型。

密集任务共享骨干、解码器和损失。任务差异主要通过数据表示表达；稀疏坐标另加预测分支。

放在相关工作中：它新在哪里？

Marigold 等工作已把图像扩散模型用于深度估计；DepthCrafter、NormalCrafter 等进一步利用视频生成先验。本文的组合是：原生视频骨干、文字控制的多种密集任务、一次前向预测，以及稀疏 token 扩展。与免训练的视频生成提示方法相比，它需要专门后训练；与图像领域的 Vision Banana 相比，它处理视频时空信息。这里概括的是作者在 §2.3 中的定位，并非宣称每个组成部分都首次出现。

结果：按任务比较单独与联合训练

Section titled “结果：按任务比较单独与联合训练”

表 1 按任务比较结果。绿色为单任务训练，橙色为多任务联合训练；切换数据集查看差异。

联合训练并非所有任务都提高

联合训练改善了前景分割，但深度和相机位姿没有普遍改善。3D 关键点联合训练退化，并影响密集任务。EMDB 的 generalist 结果为“∼”；71.8 属于 specialist。

作者认为新增 token 和坐标回归可能改变预训练表示与注意力。但论文没有独立验证具体原因。

相同后训练数据下，WAN 表现更好。但容量、预训练数据和预算不同，无法单独确定生成预训练目标的作用。增加数据集还同时改变了数量与组成。

论文所说的“7–500 倍更少数据”需结合具体比较口径理解。以表 2 的帧数为例，86M / 1.23M ≈ 70，600M / 1.23M ≈ 488；这些是表内数量比，不代表同等性能，也没有计入 WAN 的大规模生成预训练。

方法：把多步生成改为单次预测

Section titled “方法：把多步生成改为单次预测”

生成模型从噪声出发，多次调用 DiT。GenCeption 输入真实视频的压缩表示，固定 t = 0，只调用一次 DiT。输出取负后作为目标模态的压缩表示。

查看输出取负的公式与说明

为什么输出要取负？

v = ε − x0   ⇒   −v = x0 − ε

按论文约定，预训练网络预测噪声与干净表示之差。作者报告输出取负有助于收敛。取负本身不会去噪，感知映射仍需监督训练。

ŷ = D(−Fθ(E(x), c, t = 0))

E/D 表示视频 VAE，F 表示后训练后的 DiT，c 表示任务文字。此公式用于解释计算过程。

单步到底有多快？
论文 §4.2，单个 v6e TPU，81 帧、480 × 832；均为作者报告
DiT 规模总耗时其中 DiT吞吐报告内存
1.3B5.92 s0.96 s13.6 FPS15.3 GB
14B10.03 s5.11 s8.0 FPS42.8 GB

论文另列文本编码器约 10 GB、VAE 约 0.25 GB，可卸载到主存以交换速度与内存。不能由“50 步变 1 步”直接推算整体加速 50 倍，也不能将 TPU 测量直接当作本地 GPU 性能。

任务表示：图像与坐标

Section titled “任务表示：图像与坐标”

密集任务都编码成三通道图像。深度、分割将标量复制到三个通道；法线三个分量各占一个通道；DensePose 也用三通道。这样可复用视频解码器。

查看相机射线与关键点的表示细节

相机射线的六个分量怎样保存

每条相机射线有三维原点和三维方向。中心区域存原点，外围存方向；通过空间布局保存六个分量。色块只演示布局。

关键点是一条额外分支

坐标预测另加可学习 token，每个原始视频帧一个。DiT 处理后，由 MLP 输出每帧的 K 维目标。空间位置可学习；时间位置映射到压缩时间轴，并使用 3D RoPE。

“共享骨干”不等于“完全相同的输出头”。密集任务沿用 VAE 解码器；稀疏任务使用额外 token 与 MLP。联合训练这两条分支的困难，会在实验中再次出现。

训练数据与目标

Section titled “训练数据与目标”

密集任务在压缩表示空间计算 L₂ 损失，稀疏任务在坐标空间计算。深度先除以场景中位深度，再映射到 [0, 1]。

d = z / median(z)
d′ = clip(α · ln(1 + d), 0, 1)

作者用 800 个人物资产和 200 种动作生成 7,500 段视频。Blender 提供深度、法线、分割；骨架提供关节标签。输入、目标和文本编码提前缓存。

800 × 200 不是实际视频数量。正文明确报告 7,500 段。表 2 的帧数也应按原表读取，不能简单乘以每次训练采样的 81 帧。

深度还使用 TartanAir、Virtual KITTI、MVS Synth；相机轨迹使用 TartanAir。指代表达分割使用 MeViS、Ref-COCO、YouTube-VOS 的真实数据，并非所有任务只用合成数据。

训练配方与复现缺口

骨干 WAN 2.1；每次输入 81 帧、24 FPS、480 × 832；VAE 时间下采样因子 4，空间因子 8。使用 256 个 v6e TPU、batch size 64、Adam、学习率 5 × 10⁻⁵、15,000 步，前 250 步线性 warmup。还使用梯度裁剪，以及梯度范数过大时丢弃 batch。

论文未给出全部训练配置，包括裁剪阈值和完整任务比例。本页未复现训练。相同 L₂ 形式不代表各任务的尺度和难度相同。

泛化示例与结论限制

Section titled “泛化示例与结论限制”

下图是论文图 10(b)，展示真实视频、多实例和动物的定性结果。每行依次为输入、法线、深度、分割和关键点；它不能替代带真值的分类评测。

证据支持

经后训练，生成预训练权重可用于多种感知任务。密集任务可共享表示、骨干和解码器，多个基准的结果有竞争力。

尚未建立

任意任务零样本求解；所有模态都能无损联合训练；严格控制预算后的预训练目标优越性；普遍的物理推理或行动规划能力。

这里的“未见类别”指感知后训练数据未覆盖，不代表生成预训练从未见过。

对视觉决策研究的启发

用于视觉决策前，还需验证对象、几何和运动识别，再用相同动作协议测决策。本论文没有证明规划或安全决策会随之改善。

阅读检查：三个容易混淆的问题

换提示词就能把原始 WAN 变成感知模型？不能。本文方法包含监督后训练与计算路径改造。

表中最佳成绩都来自同一个模型？不是。表 1 区分 specialist 与 generalist；关键点联合训练还存在退化。

少用后训练数据，等于总训练成本更低？不能这么推断。继承的生成预训练成本没有在这些数量比中消失。

术语速查

VAE / 潜变量把视频压缩到较小的连续表示，再解码回图像空间。
DiT扩散 Transformer；此处继承其权重，并后训练为单次前向预测器。
Dense / Sparse逐像素密集输出 / 少量结构化坐标输出。
Specialist / Generalist按任务单独训练的模型 / 多任务联合训练的模型。
Raymap / RoPE以像素图组织相机射线 / 给 Transformer 提供相对位置信息的旋转位置编码。
