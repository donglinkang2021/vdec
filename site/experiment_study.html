三模型规划与视觉推理实验§

实现协议为 snake-bench-v8，沿用 main-v1 冻结数据与指标。历史 v7 结果仍可离线读取。数据、模型真实结果、规则 oracle 和测试替身结果必须分别解释。

生成和读出§

默认 --sampling model_default 读取 checkpoint 的 generation_config.json，用当前 Transformers 库默认值补齐缺失字段，并把原文件 SHA-256、原值和解析值写入 run.json。缺少文件时明确失败；通过 --generation-config FILE 显式覆盖。recommended 保留旧固定参数；probe 为 T=1/top_p=1/top_k=-1 的 thinking 加 greedy plan；greedy 全部 greedy。boxed 读出始终使用中性参数，与生成采样分离。

Qwen3.5-4B 本地 checkpoint 没有该文件。experiments/qwen35_model_card_sampling.json 是来自本地模型卡、带来源哈希的显式替代配置，不是 checkpoint 默认文件。用户已确认采用；研究矩阵默认加载 experiments/snake_generation_configs.json 显式映射，单独运行 CLI/冒烟脚本仍需传入 --generation-config experiments/qwen35_model_card_sampling.json。实际参数及来源随 dev 冻结。

条件 生成 执行上下文
no_plan 无 当前截图与问题
shared_full thinking + plan 同一份完整 thinking + plan
shared_plan_only 与 full 共享生成结果 仅保留 plan
shared_no_think 关闭 thinking 生成 plan 直接 plan
manual_plan 无 固定任务清单
neutral_prefix 无 与人工清单 token 长度接近的中性段落
per_step_cot 当前问题独立 thinking 原始 thinking token、结束标记、boxed 直接读出

人工清单在 prefixes.py 固定，亦可用 --manual-plan-file 替换；不按 plan 生成预算裁剪。每个 plan 事件保留实际正文、token 长度和来源哈希。per_step_cot 使用 --step-thinking-tokens 128/256/512，不生成中间 plan；choice 每个排列独立，yes/no 每个候选独立。自然结束立即读出，耗尽预算补齐原生结束标记，异常提前结束记失败。

--repeat-id 与 --seeds 不同：前者是覆盖完整数据集的独立生成重复，后者分配 family 的共享 plan。分片不会改变同一个实际问题的 RNG。所有模型保留各自原生模板，Gemma 使用通道结束标记。

运行顺序§

在项目根目录使用同一虚拟环境、源码快照、vLLM 配置、精度及缓存设置。experiments/snake_models.json 给出三个模型路径，可复制后改为分配节点可访问的路径。

# 仅查看矩阵，不加载权重、不提交 GPU
PYTHONPATH=src:. .venv/bin/python scripts/snake_study.py matrix \
  --models experiments/snake_models.json --stage baseline

# 模板检查，使用真实 tokenizer / processor，无权重
PYTHONPATH=src .venv/bin/python run.py --model models/Qwen/Qwen3-VL-4B-Thinking --preflight

# 单模型 GPU 冒烟：128-token 共享 planning，三档当前问题 thinking
PYTHONPATH=src .venv/bin/python scripts/smoke_snake_reasoning.py \
  --model models/Qwen/Qwen3-VL-4B-Thinking --output outputs/smoke-qwenvl

# 完整 dev 基线；输出目录必须不存在
PYTHONPATH=src:. .venv/bin/python scripts/snake_study.py matrix \
  --models experiments/snake_models.json --stage baseline --execute --output outputs/study-dev-baseline

随后按 shared、prefix、cot 分阶段执行。shared 包含 plan 128/512/1024、四种生成方式、三个重复；cot 包含 128/256/512、三个重复。所有阶段包含四个静态榜和两种读出。每个 split 共 564 个独立运行目录：baseline 12、shared 432、prefix 12、cot 108；其中每个 shared full/plan-only 配对在同一个运行内生成一次。主流程不会重复运行 no_plan。

显式覆盖映射文件格式为 {"qwen35-4b":"experiments/qwen35_model_card_sampling.json"}，通过矩阵命令的 --generation-configs FILE 使用。运行失败立即停止，保留已有输出；工具不会覆盖或自动重试部分运行。

# 所有参数应为实际运行目录，而非包含多个运行的父目录
PYTHONPATH=src:. .venv/bin/python scripts/snake_study.py compare \
  outputs/RUN_BASELINE outputs/RUN_CONDITION --output outputs/comparison-dev

# 完成 dev 后冻结；test 必须匹配已完成的 dev 配置、源码、启动器和采样文件
PYTHONPATH=src:. .venv/bin/python scripts/snake_study.py freeze \
  outputs/RUN_BASELINE outputs/RUN_CONDITION --output outputs/dev-freeze.json
PYTHONPATH=src:. .venv/bin/python scripts/snake_study.py matrix \
  --models experiments/snake_models.json --stage baseline --split test \
  --freeze-file outputs/dev-freeze.json --execute --output outputs/study-test-baseline

# 从完整 dev Decision 比较结果选择闭环配置；默认仅列出，追加 --execute --output 才运行
PYTHONPATH=src:. .venv/bin/python scripts/snake_study.py episodes \
  --comparison outputs/comparison-dev/comparison.json

闭环使用相同 30 个 seed、128 步上限，包含无计划、人工计划、每模型每读出的最佳生成计划和最佳 per-step CoT。共享计划按 dev Decision 安全率、执行时间顺序选择；CoT 同分选短预算。Episode 使用自己的任务规划提示重新生成计划。随机基线只随 no_plan 运行。

分数和蒸馏接口§

每个 run 保留榜单、原始事件、分层诊断、视觉格子混淆、Safety 配对判断、危险召回、误报及延迟。比较表按模型、任务、读出、条件、采样和预算分组，先按重复聚合，再以 family 为单位进行 2000 次配对 bootstrap；保留同 family 内全部题目与排列，Safety/Decision 保持层等权。单独报告重复分数和标准差。未完成配置不排名，比较输出展示其失败率、缺失数与不支持数。

Readout 的一致性不是决策正确性。静态收益必须结合 Decision 和闭环食物数、可避免碰撞、重复状态与延迟解释。前缀中性对照只是长度接近，不声称精确消除了全部语义影响。

PYTHONPATH=src:. .venv/bin/python scripts/snake_study.py export-teacher \
  --baseline outputs/RUN_NO_PLAN --teachers outputs/RUN_COT_REPEAT0 outputs/RUN_COT_REPEAT1 \
  --output outputs/teacher-evaluation

导出要求两个不同 repeat 的同模型、同预算、同配置 CoT 运行，逐项核对当前图像、问题和语义候选顺序。保存可重建并校验哈希的 PNG、两次候选分布及平均值、无思考 p0、推理 token/终止状态；yes/no 额外保留原始二元概率。

导出标记 purpose=evaluation_only。正式训练集必须另建，并与 benchmark 的 dev/test family 隔离。本轮不启动 vdistill 训练。SII-Decision 的候选分布蒸馏可作为后续损失参考，但官方语言 backbone 路径需要多模态适配：论文 v2 §6、官方 learning.py。

验证§

PYTHONPATH=src:.:tests .venv/bin/python -m unittest discover -s tests
PYTHONPATH=src .venv/bin/python -m vdecision.benches.snake.datasets_audit

离线模板检查不等于 GPU 推理检查；测试替身通过不代表已获得三模型分数。GPU 冒烟脚本的 smoke.json 区分 not_performed、failed、passed，完整 benchmark 以 run 原始事件及汇总为准。
